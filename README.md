# Fedora Dotfiles

My personal Fedora Linux configuration, built around
Hyprland and a graphite aesthetic with Fedora blue accents.

## Environment

- OS: Fedora Linux
- Window Manager: Hyprland
- Terminal: Kitty
- Shell: Bash
- Status Bar: Waybar
- Application Launcher: Wofi
- Notifications: Dunst
- Lock Screen: Hyprlock
- Idle Management: Hypridle
- Shell Prompt: Starship

## Theme

- Background: #111111
- Foreground: #D6D6D6
- Fedora Blue: #3C6EB4
- Bright Blue: #51A2DA

## Structure

| Directory | Purpose |
|---|---|
| hypr | Hyprland, Hyprlock, Hypridle |
| kitty | Terminal configuration |
| waybar | Status bar |
| wofi | Application launcher |
| dunst | Notifications |
| starship | Shell prompt |
| kvantum | Qt theme configuration |

## Disclaimer

These are my personal configurations.
Some settings may require adjustment for other systems.
